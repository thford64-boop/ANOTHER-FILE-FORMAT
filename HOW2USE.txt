=========================================================
            QUK 6.0 - OFFICIAL HOW 2 USE (H2U)
=========================================================

QUK (pronounced 'Quick') is a powerful, line-based language 
designed for games, tools, and visual scripts.

---------------------------------------------------------
1. GETTING STARTED
---------------------------------------------------------
* Create a text file and rename the extension to .quk
* Drag the .quk file onto the quk_engine.exe to run it.
* Comments start with // and are ignored by the engine.

---------------------------------------------------------
2. THE VARIABLE SYSTEM
---------------------------------------------------------
To save data, use SET. To use that data later, put a $ 
in front of the name.
   SET score 0
   TEXT "Your score is $score" #ffffff 100 100

---------------------------------------------------------
3. LOGIC & FLOW (The Brain)
---------------------------------------------------------
QUK uses "Labels" and "Gotos" to move around.
   :MyLoop
   ADD score 1
   GOTO MyLoop     <-- This creates an infinite loop!

Use IF commands to check conditions:
   IFEQ $score 10  <-- Only runs the next line if score is 10
   POPUP "You reached 10 points!"

---------------------------------------------------------
4. TOP 10 COMMANDS TO KNOW
---------------------------------------------------------
1. BG [color]         - Change the window background color.
2. DRAWBOX [id] [x] [y] [size] [color] - Create a square.
3. MOVE [id] [x] [y]  - Move a box or circle.
4. RAND [v] [min] [max]- Generate a random number.
5. WAIT [sec]         - Pause the script.
6. WAITCLICK          - Wait for a mouse click to continue.
7. SOUND [hz] [ms]    - Play a beep sound.
8. POPUP "msg"        - Show a Windows alert box.
9. FLASH              - Make the screen flash white.
10. EXIT              - Close the program instantly.

---------------------------------------------------------
5. PRO MATH
---------------------------------------------------------
QUK supports ADD, SUB, MULT, DIV, POW, and SQRT. 
Example: MULT score 2 (Doubles the score variable).
